FORGE — application web de musculation

CONTENU
- index.html : application interactive
- manifest.webmanifest : paramètres d'installation
- sw.js : cache hors-ligne de base

POUR L'UTILISER SUR IPHONE
1. Cette archive doit être hébergée sur une adresse HTTPS publique pour être installable comme PWA.
2. Décompressez le ZIP et publiez les 3 fichiers à la racine d'un hébergement statique HTTPS (par exemple Netlify Drop ou GitHub Pages).
3. Sur l'iPhone, ouvrez l'adresse publiée dans Safari.
4. Touchez Partager, puis « Sur l'écran d'accueil », puis Ajouter.

FONCTIONS
- 3 séances intégrées : lundi, mercredi, vendredi
- exercices, séries, répétitions, repos et consignes d'effort
- chronomètre de repos
- saisie des charges, répétitions et RIR/échec
- mémoire par exercice : dernière charge/répétitions et meilleure charge enregistrée
- préremplissage des champs avec la dernière performance du même exercice
- historique local et poids du corps
- export JSON des données

CONFIDENTIALITÉ ET LIMITES
Les données sont enregistrées dans le stockage local du navigateur sur cet appareil. Elles ne sont pas synchronisées entre appareils. Exportez régulièrement vos données. Cette archive n'est pas encore publiée sur Internet et ne possède donc pas d'URL publique à ouvrir directement.
